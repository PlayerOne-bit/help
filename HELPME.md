## HELP WITH SYNTAX FOR MD

### Headers
```
# Heading 1
## Heading 2
### Heading 3
```
### Text Emphasis
```
*italics* or _italics_
**bold** or __bold__
***bold with italics***
```
### Lists
```
- unordered list 1
* unordered list 2
+ unordered list 3

1. ordered list
```
### Links and Images
```
[Hyperlink](insert link)

!: ![Alt text](image file name)
```
### Block Quotes
```
> block quote
```
### Code
```
programming language
`inline code`
``` code blocks ```
```
### Line Breaks & Paragraphs
```
blank line
two trailing spaces and press enter
```
### Create Header
```
| Header 1 | Header 2 |
| -------- | -------- |
| Cell 1   | Cell 2   |
```
### Check List
```
[ ] Uncheck
[X] Check
```
### Strikethrough & Highlights
```
~~striketrough~~
==highlight==
```
