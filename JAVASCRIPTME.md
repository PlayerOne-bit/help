# JAVASCRIPT SYNTAX FULL
### Types
```javascript
console.log(typeof ""); //string
console.log(typeof 0); //number
console.log(typeof 0n) //bigint
console.log(typeof NaN); //number(Not a Number)
console.log(typeof false); //boolean
console.log(typeof null); //object(null)
console.log(typeof []); //object(array)
console.log(typeof {});//object
console.log(typeof (()=>{})); //function
console.log(typeof undefined); //undefined
```
### Conditions
```javascript
//All output is true
console.log(!false); //negates boolean
console.log(true && true); //both should be true
console.log(true || false); //either should be true
console.log(0 == "0"); //value is same
console.log(0 === 0); // type and value is same

```
